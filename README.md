### Ninja/Player Model
The player model is not included in this repository. The test asset was created with [Mixamo](https://mixamo.com), which allows for free usage of assets, however free distribution of the raw assets, such as the mesh and animiation files is explicitly forbidden. To create the player class as it is, it was necessary to rip the assets into the raw pieces, which is not forbidden under the Mixamo TOS, however putting them under this repo probably would be. 

Eventually, I do plan to create a custom character model with custom and better animations. 

If you want to recreate this behavior, you can use Mixamo to download the FBX files for animations on a given character, and then open them with Godot. Actions > Set Mesh/Animation Save Paths will let you toss them into individual assets for using within a scene tree.
